# Mismamente - Plataforma de Integración y Convivencia Escolar

**Eslogan:** «Tu personalidad, tu comunidad»  
**Público Objetivo:** Estudiantes de preparatoria.  
**Tecnologías:** HTML5, CSS3, JavaScript puro (Vanilla JS). Sin frameworks ni dependencias externas.

---

## 1. Descripción del Proyecto

Mismamente es una aplicación web responsiva diseñada para fortalecer el sentido de pertenencia y fomentar amistades en instituciones educativas de nivel medio superior. Agrupa simbólicamente a los estudiantes en **8 familias animales** a través de un cuestionario recreativo de autoconocimiento, facilitando la creación de vínculos mediante intereses compartidos (música, arte, videojuegos, deportes, cine) y retos semanales anónimos.

---
